# 🔎 FrameFind

> **Find the image that matches your idea.**

FrameFind is a clean, responsive image-search interface designed to help users discover visual inspiration by topic. In Part 1, the project focuses on building the complete front-end structure and search experience; image fetching and rendering will be added in Part 2.

## ✨ Features

- 🔎 Accessible search input with a clear label
- 📱 Responsive layout for desktop, tablet, and mobile
- 🧩 Responsive CSS Grid prepared for image results
- 🏷️ Quick-pick topic chips: Nature, Cities, Animals, and Space
- 🧹 Clear search control
- 📌 Sticky navigation header
- 💬 Empty-state message and result-count placeholder

## 🎨 Design Decisions

**1. Warm cream + teal theme**  
I chose a cream and teal colour palette to give FrameFind a calm, modern visual identity and make it clearly different from the purple PixelPulse reference.

**2. Split introductory layout**  
I placed the app introduction beside the search panel so users immediately understand what the application does before interacting with it.

**3. Quick-pick suggestions**  
I added topic chips so common searches are visible at a glance and can later become one-click searches when functionality is added.

## 🛠️ Built With

- CSS3
- Vanilla JavaScript

No frameworks, libraries, or build tools are used.

- **Part 1 — Scaffold & UI:** Structure, styling, search interface, and responsive results grid.
